## 🌐 1. Overview

This guide explains how to connect **SMART-MED over the INTERNET** using **Supabase** (Free Cloud PostgreSQL Database with REST API).

With Supabase Cloud Integration:
- **LAPTOP 1 (Ambulance)** can be in an actual moving vehicle connected to 4G/5G mobile internet.
- **LAPTOP 2 (Hospital)** can be at the hospital desk connected to hospital Wi-Fi anywhere in the world.
- Communication takes place securely over **HTTPS REST API**.

---

## ⚡ 2. Step 1: Create a Free Supabase Project

1. Go to [https://supabase.com](https://supabase.com) and click **Start your project** (Sign in with GitHub or Email).
2. Click **New Project**.
3. Fill in the details:
   - **Name**: `SMART-MED`
   - **Database Password**: Choose a strong password.
   - **Region**: Choose the nearest region (e.g. `South Asia (Mumbai)` or `East US`).
   - **Pricing Plan**: Free Tier.
4. Click **Create new project** and wait ~1 minute for deployment.

---

## 🔑 3. Step 2: Get your Supabase URL & Anon API Key

1. In your Supabase Dashboard, click on the **Project Settings** (gear icon) on the left sidebar.
2. Select **API** under Configuration.
3. Copy two values:
   - **Project URL** (e.g. `https://xyzabcdefghijklm.supabase.co`)
   - **anon / public Key** (e.g. `eyJhYmdj...`)

---

## 📜 4. Step 3: Create the Database Table in Supabase

1. On the left sidebar of your Supabase Dashboard, click **SQL Editor**.
2. Click **New Query**.
3. Paste the following SQL script:

```sql
-- Create SMART-MED Telemetry Transmissions Table
CREATE TABLE transmissions (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    patient_id TEXT NOT NULL,
    patient_name TEXT,
    age INT,
    gender TEXT,
    heart_rate INT,
    spo2 INT,
    systolic_bp INT,
    diastolic_bp INT,
    blood_pressure TEXT,
    temperature NUMERIC,
    respiratory_rate INT,
    patient_status TEXT,
    emergency_level TEXT,
    reasons TEXT,
    data_source TEXT,
    transmitted_at TEXT
);

-- Enable Row Level Security (RLS)
ALTER TABLE transmissions ENABLE ROW LEVEL SECURITY;

-- Create Policies to Allow Secure Telemetry Reading & Writing
CREATE POLICY "Allow public select on transmissions" 
    ON transmissions FOR SELECT USING (true);

CREATE POLICY "Allow public insert on transmissions" 
    ON transmissions FOR INSERT WITH CHECK (true);
```

4. Click **Run** (or press Ctrl+Enter). You will see `"Success. No rows returned"`.

## 🚑 5. Step 4: Configure LAPTOP 1 (Ambulance Side)

1. Start Ambulance App on Laptop 1:
   ```bash
   python ambulance/app.py
   ```
2. Open Web Browser: `http://localhost:5001`
3. On the right sidebar, locate **Supabase Cloud Internet Mode**.
4. Set **Transmission Target Mode** to: `Supabase Cloud Database (Internet Mode)`.
5. Paste your **Supabase Project URL** and **Supabase Anon Key**.
6. Click **Save Supabase Config**.
7. Click **` Test Cloud Connection`**. You will see:
   `✅ SUPABASE CLOUD CONNECTED: Successfully connected to Supabase Cloud Database over HTTPS!`

---

## 🏥 6. Step 5: Configure LAPTOP 2 (Hospital Side)

1. Start Hospital App on Laptop 2:
   ```bash
   python hospital/app.py
   ```
2. Open Web Browser: `http://localhost:5002`
3. On the right sidebar, locate **Supabase Cloud Internet Mode**.
4. Set **Receiver Mode** to: `Supabase Cloud Database (Internet)`.
5. Paste the same **Supabase Project URL** and **Supabase Anon Key**.
6. Click **Connect Supabase Cloud**.

---

## 🎉 7. Step 6: Test Telemetry Transmission over Internet

1. On **Laptop 1 (Ambulance)**:
   - Watch the 3-minute timer tick down, OR click **` SEND LATEST DATA NOW`**.
2. On **Laptop 2 (Hospital)**:
   - Within seconds, the new vital telemetry payload will land in the **Historical Patient Telemetry Transmissions** table and update the trend graphs live over the Internet!
